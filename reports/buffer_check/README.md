# Savings buffer check (plan P7d, Phase C)

Generated by `cd backend && uv run python -m ml.buffer_check`; do not edit by hand.

**What this is.** The direct simulation (the quantity Engine 2's label is built from, D-07) of 10 purchases per persona on SPayLater (RM 100 to RM 1,500, 3 or 6 instalments), run with no savings buffer and with one, using the served forecast network. A buffer is an opening balance added to the first month's margin. **What it is not:** a model score, a result on real students, or a forecast of anyone's finances. It is three synthetic ledgers.
